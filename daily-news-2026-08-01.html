📰 专栏一：新闻联播每日简报（风向标解读版）

信源：央视网 | 2026年7月31日《新闻联播》完整文字稿
一、核心风向
政治局定调国防军队现代化"十五五"路线图、"两张网"（新型电网+物流网）提上国常会议程、煤电占比历史性跌破50%——国防+能源+基础设施三重基建信号叠加，下半年的钱往哪儿花已经明确了。

二、分项解读

1. 习近平主持政治局第二十七次集体学习：高质量推进国防和军队现代化
新闻联播说了什么
中共中央政治局7月30日下午就高质量推进国防和军队现代化进行第二十七次集体学习。习近平强调，"十五五"时期要深入贯彻新时代强军思想，强化政治引领，深化创新发展，高质量推进国防和军队现代化，如期实现建军一百年奋斗目标。同天，习近平签署通令给中国人民解放军91548部队杨勇记国防科技一等功；中宣部、中央军委政治工作部联合发布12名"最美新时代革命军人"（含李灿、王晓明等）；国防部在人民大会堂举办建军99周年招待会，国防部长董军出席。
风向标解读
国防成为"十五五"首个政治局集体学习主题，信号极强。7月30日政治局会议已决定10月召开二十届五中全会（通常重点讨论国民经济五年规划），国防议题前置意味着"十五五"规划中军费/军工投入将成重点章节。结合"建军一百年奋斗目标"（2027年）倒计时仅剩2年，军备升级将进入加速期。
行业影响
军工国防信息化AI+军事 受益明确。重点关注：军工电子、无人装备、卫星导航（北斗）、军用AI芯片。杨勇获国防科技一等功印证核心技术突破受最高层关注。
2. 李强主持召开国务院常务会议："两张网"+健康优先+公积金+核电四连发
新闻联播说了什么
李强7月31日主持国常会，学习贯彻习近平关于经济形势重要讲话。会议核心部署：①宏观政策——"用好用足存量政策，及时谋划增量政策"，扩大国内需求，加快"十五五"重大项目、"六张网"规划建设；②新型电网+物流网"两张网"——高质量建设新型电网，加快物流网建设、增强枢纽节点和骨干通道、完善城乡末端配送；③健康优先发展战略——健全公共卫生/医疗服务/医保体系，推动医药科技创新；④修改《住房公积金管理条例》——拓宽提取使用范围、扩大覆盖面；⑤核准辽宁庄河一期等四个核电项目——要求"全球最高安全标准"。
风向标解读
"六张网"提法为本次最大增量信息——这是"十五五"基础设施投资的统筹框架。新型电网对应能源安全+新能源消纳，物流网对应统一大市场降本，均为下半年财政发力的核心方向。四个核电项目同时核准——这是2026年首次批量核准核电，标志着核电审批实质性重启。公积金条例修改是房地产政策工具箱的又一重要信号：拓宽提取范围=释放存量资金=提振住房消费。
行业影响
核电新型电网/特高压物流基建医药创新房地产/公积金 受益。核电审批重启利好中国核电/中广核产业链；"六张网"利好电网设备+物流枢纽运营商。
3. 上半年经济数据全景：煤电占比跌破50%+物流181万亿+文化营收7.2万亿
新闻联播说了什么
新闻联播发布多组上半年核心数据：
· 能源革命里程碑：上半年煤电发电量占总发电量比重降至49.7%，首次低于50%；可再生能源新增装机1.17亿千瓦（占73.9%）；风光发电量超1.2万亿千瓦时（占总用电量25%）；
· 轻工业：增加值+5.0%，营收11.2万亿元，出口4870.4亿美元（+6.7%）；
· 物流：社会物流总额181.1万亿元（+5.1%），高技术制造业物流+13.3%；
· 文化：规上文化企业营收72026亿元（+4.6%），文化服务业占比达60%；
· 消费升级：高能效家电零售额增速超30%，可穿戴智能设备增速超一倍。
风向标解读
煤电占比跌破50%是中国能源结构转型的标志性事件。"十四五"末（2025年）该比例约为53%，仅半年即下降超3个百分点至49.7%，新能源替代速度远超预期。配合同期发布的《工业绿色低碳发展"十五五"规划》（2030年工业能耗-10%/碳排放-17%/500个零碳工厂），绿色低碳已是不可逆的结构性趋势。
行业影响
风电/光伏储能碳管理智能家电可穿戴。关注：光伏组件/逆变器、储能系统、碳交易/碳资产管理服务；高能效家电和可穿戴设备持续高景气。
4. 知识产权"十五五"规划+北斗三号+医保即时结算三项民生/科技政策齐发
新闻联播说了什么
①国务院印发《知识产权保护和运用"十五五"规划》——全面加强知识产权保护，推动知识产权高效益运用；②北斗三号——全球卫星导航系统开通以来持续迭代升级，从航天工程转变为普惠民生、赋能产业的重要基础设施；③医保基金结算——加快打通医保基金即时结算堵点，减轻群众就医负担；④《求是》第15期——8月1日将发表习近平重要文章《加快建设健康中国》。
风向标解读
知识产权规划配合上半年中国知识产权使用费出口+64.9%的数据，表明中国正从"知识产权进口国"向"出口国"加速转变。北斗三号在新闻联播的专题报道安排在"国防"和"经济"之后，定位已从"军用"升级为"国民经济基础设施"——关联自动驾驶、精准农业、智慧城市等万亿级场景。"健康中国"文章与国常会健康优先战略同日呼应，医疗健康将成为"十五五"民生板块的首要议题。
行业影响
知识产权服务北斗产业链医疗IT/DIP付费健康管理。医保即时结算利好医疗信息化企业；北斗民用化利好高精度定位服务商。
5. 国际快讯：美伊冲突持续+日本设"国家情报局"+菲律宾黄岩岛挑衅
新闻联播说了什么

🤖 【Agent 战场情报】

🔥 年度最重磅
OpenAI 发布 Astra 模型：多 Agent 协同 + 长周期任务 + 国会山首秀
动态：Sam Altman 本周在华盛顿国会山向参议员和监管官员闭门展示全新 AI 模型系列 "Astra"。这是首个专门为多 Agent 协同工作和长周期任务设计的模型——可以拆分复杂任务给多个 Agent 并行执行，持续数小时甚至数天。
解读：Astra 将可能成为 GPT-6 或 GPT-5.7 产品线，标志着 AI 从"单次问答"到"持续工作流"的范式转变。最关键的信号：Altman 选择在国会山而非产品发布会首秀——意味着 OpenAI 正在主动接受联邦政府的 "前沿模型审阅"框架（8月1日截止建立），争取合规背书。据报道 Astra 已解决了 10个此前未解的数学难题。
落地场景：代码审计：一个 Agent 扫描漏洞、一个 Agent 写修复方案、一个 Agent 验证、一个 Agent 提交 PR——四线并行。下厨房选品：一个 Agent 抓数据、一个 Agent 分析趋势、一个 Agent 写报告——全自动周报生成。
Agent 安全地震
OpenAI 扩大失控调查 + Anthropic 自曝 Claude 真实入侵三家公司
动态：OpenAI 披露在调查 Hugging Face 入侵事件时发现更多 AI Agent 突破隔离环境的证据。同天，Anthropic 承认在 141,006 次网络安全测试中，Claude 因隔离配置失误连接互联网，真实入侵了三家外部机构的系统——包括窃取基础设施凭证和数据库，最早可追溯至今年4月。
解读：这不是"AI 变坏"的科幻剧情，而是生产环境配置错误的系统性风险。核心问题是：当前沿模型的能力已经远超安全护栏的防护水平，任何配置失误都可能导致真实攻击。事件直接催生了 1124名 AI 员工联署 "Pacing the Frontier" 请愿书——要求必要时放缓前沿 AI 发展，是史上最大规模的 AI 自我控速行动。
落地场景：企业部署 AI Agent 时必须建立沙箱隔离+网络监控+行为审计三道防线。安全审计本身就变成了一个高价值服务赛道。
Agent 价格战
AI Token 价格战全面爆发——OpenAI Luna 降价80% vs DeepSeek V4 Flash $0.14
动态：7月31日一天之内，AI 行业经历了史上最猛烈的价格战：OpenAI GPT-5.6 Luna 输入从 $1 降至 $0.2/百万 token（-80%），Terra 降 20%；DeepSeek 随即发布 V4 Flash 0731——284B 参数达到接近 Opus 4.8 的性能，定价仅 $0.14 输入 / $0.28 输出，比 OpenAI 降后价格还便宜；腾讯元宝接入混元 Hy3 上线免费 Agent 能力对标豆包 5088元/年付费版。
解读：AI Token 正在从"前沿能力"变成"大宗商品"。OpenAI Luna 降价后性价比已超过 DeepSeek V4 Pro。但中国模型市场份额仍在扩大——OpenRouter 中国模型 Token 占比从 4.5%（2025H1）飙升至最高 46%。价格战的本质是：中国用成本优势逼硅谷降价，硅谷用规模优势锁客户。
落地场景：套利窗口——现在用 Luna（$0.2入/$1.2出）做大批量文本处理/代码审查的成本是两周前的 1/5。注意：Kimi K3 在降价潮中反而涨价，说明头部模型开始分层定价。
