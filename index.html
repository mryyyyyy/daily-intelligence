3. Etched Transformer专用芯片成功流片，签下10亿美元大单

🔬 芯片突破 💰 10亿美元订单

核心数据：Etched A0芯片从台积电N4P工艺成功流片。8亿美元融资+10亿美元客户大单。投资方：Karpathy、李飞飞、Hinton。团队400+工程师（来自英伟达/谷歌TPU/博通/SK海力士/台积电）。第一批机柜今年夏天出货。

技术突破：

• 低电压推理（LVI）：芯片数学模块在不到大多数AI芯片一半的电压下运行，万亿参数级稀疏MoE在80%+峰值FLOPs下运行无热降频

• 集群规模内存（CSM）：HBM/SRAM混合设计，跨芯片超低延迟高带宽互连，解决mem2mem延迟问题

• 架构思路：不做通用芯片，从Day 1只做Transformer专用——从晶体管到token统筹设计

策略解读：这是AI芯片从"通用GPU"走向"专用ASIC"的里程碑。如果Etched验证成功，将颠覆英伟达的绝对垄断——不是用更强的通用GPU，而是用更专的Transformer芯片。创始团队2024年入选Thiel Fellowship，全00后哈佛辍学，典型"硅谷范儿"。

4. 英伟达开源ASPIRE机器人技能库，Jim Fan：范式变了

🤖 具身智能 🔬 研究突破

核心概念：ASPIRE=Agentic Skill Programming through Iterative Robot Exploration。让机器人在执行任务时记录失败+看轨迹+修程序+沉淀Skill——形成持续学习的技能库。背后调用GPT/Claude像研究员一样分析失败原因。

范式转变（Jim Fan）：训练从梯度下降→不断打磨Skill；训练产物从模型权重→持续扩展的技能库；分布式训练从多GPU→一群Agent各自练习不同技能再汇总。

关键实验：Robosuite双臂物体交接：成功率从20%→92%；LIBERO-90积累Skill Library后迁移到未见过任务：成功率从几乎0→31%。

策略解读：Code as Policy+Skill积累=机器人不再"每次从零开始"。这跟人类的"踩坑笔记"逻辑完全一致——"当机器人完成第100个任务时，终于不再像完成第1个时那样一无所知"。具身智能从"模型训练"进入"经验积累"时代。
