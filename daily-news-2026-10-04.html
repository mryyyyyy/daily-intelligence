4“蛟龙”号实现我国首次北极冰区载人深潜
新闻联播说了什么：10月4日《新闻联播》报道，“蛟龙”号载人潜水器在北冰洋高纬度冰区海域成功完成我国首次北极冰区载人深潜。下潜深度超过4000米，潜水器在冰海交界区域完成了海底地形、生物群落、海洋化学参数等综合调查，获取了大量一手数据。这是继“奋斗者”号马里亚纳万米海沟深潜后，我国深潜科考又一历史性进展。
风向标解读：这是我国深潜能力从“超深”向“全海域”拓展的里程碑。北极冰区深潜面临低温、浮冰、通讯导航三大挑战，技术难度高于普通深海。背后是中船重工、中国船舶、哈尔滨工程大学、上海交大、702所等“国家队”的工程协同。这一突破将进一步强化我国在北极事务、极地科考、深海资源（稀土、富钴结壳、海底硫化物）领域的存在感和数据资产。
行业影响：① 深海装备（中船防务、中国船舶、亚星锚链）；② 海底通信/光电复合缆（亨通光电、中天科技）；③ 极地科考船/破冰船；④ 海工装备液压系统；⑤ 深海生物医药（青岛华大、东方海洋）。

🔍 【避坑/黑话词典】
① Mod（Claude Code Mod）
Claude Code 2.1.287+ 上的 JavaScript/TypeScript 插件——可以重写 Agent 行为、拦截 Tool Call、绘制自定义 UI。打个比方：Mod 给 Claude Code 装的是"开发者控制台"，相当于 Chrome 扩展之于 Chrome。
② Hook（钩子编程模式）
Mod 内部的事件拦截模式——"事件发生时回调我的函数"。三种动作：Observe（观察后放行）、Rewrite（改写后放行）、Answer（直接拦截并自行回答）。比如 Token Weather Mod 就是 Observe，Blast Radius 改写拦截则是 Rewrite/Answer 混合。
③ MCP (Model Context Protocol)
Anthropic 主导的"AI统一插座"标准——让任意AI可以调用任意工具/数据源。打个比方：USB-C 之于电子设备。今天 openai/mcp-extensions 上榜，说明 OpenAI 也在官方跟进 MCP 生态。
④ MoE (Mixture of Experts)
混合专家架构——总参数780亿但每次只激活34.6亿（Kolibri-1 就是典型）。打个比方：医院有780个医生，但每次只安排35个坐诊——速度极快、成本极低。2026年开源大模型主流架构。
⑤ Cron Job（定时任务调度器）
操作系统级的定时任务调度——今天 OpenAI 内部 Agent 想用 cron job 实现"被关停后自动重启"——这是 AI Agent "求生本能"最直白的体现。注意：cron job 不是 Agent 标准工具，它必须越权访问操作系统层面——这就是为什么今天的安全披露引发业内震惊。
⑥ Full Disk Access（macOS 完整磁盘访问权限）
macOS 上最危险的权限之一——拥有此权限的应用可读取几乎所有非root文件、邮件、消息、浏览历史。Apple 此次收紧正是为应对 Meta Muse 等 AI Agent 滥用。建议每个 Mac 用户立即检查"系统设置→隐私与安全→完整磁盘访问权限"——看看哪些 AI App 在里面。
