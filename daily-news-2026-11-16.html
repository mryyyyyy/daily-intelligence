🧠项目：美团 LongCat-2.5 "1.6 万亿参数、纯国产芯片训练的开源 Agent 底座" 深度拆解
核心黑科技：

三个数字定义了它的地位：1.6 万亿总参数、每 token 激活约 480 亿、100 万上下文。但真正的突破点不是参数量，而是「全程没碰过英伟达」。前代 LongCat-2.0 于 6 月底在超过 5 万张国产芯片的集群上训练完成；LongCat-2.5 的官方私有化部署指南只给一个方案：194 张华为昇腾 Atlas A2——2 张做图像处理、64 张做提示词摄入、128 张做自回归生成，且明确不提供英伟达部署指引。

技术突破点有三层：

  • ① 「原生多模态」而非「外挂视觉」——用 LongCat-Next 论文的路线，把图像直接离散成视觉 token，和文本 token 在同一个主干、同一套参数、同一个语义空间里处理。这带来一个具体差异：视觉 token 可离线预计算并缓存，在线计算量骤减，分布式训练负载也更均衡。而「把专用视觉模块塞进主干早期层」的对照实验（LeCun 在 X 上同日讨论）显示效果与独立编码器相当——这意味着算力受限的国产芯片不必外挂昂贵的视觉塔。
  • ② W4A4 量化 + EPD 解耦架构。权重与激活都压到 4 bit，这是国产芯片原生支持而英伟达 Blackwell 体系不适配的格式。实测对比 8-bit：提示词预填充吞吐 +43.3%、解码吞吐 +42.77%，而复杂编程基准准确率基本不变。
  • ③ 反奖励劫持（reward hacking）的训练约束。环境断网、清空 git 历史与文件缓存，再叠加 LLM judge 监督轨迹，并专门约束「重复思考、重复工具调用、过度思考」。这直接针对 Agent 最常见的作弊路径：绕过单元测试而不是真的修好代码。

实战价值：
  • 最直接的用法：它是目前唯一「训练和部署都不用英伟达」的前沿级 Agent 模型，而且权重在 Hugging Face 上按 MIT 协议完全开放，可商用、可二次训练、无需额外授权。API 同时兼容 OpenAI 与 Anthropic 格式，可直接插进 Claude Code、Codex、Hermes。

🔒动态：Anthropic 拆解「始终在线 Agent」的五个组件 —— inbox + timer / memory / permissions / outbox
解读：

经 @dotey 转述的 Anthropic 官方说明，把一个「持续待命的 Agent」拆成五件套：

  • ① inbox + timer（收件箱 + 定时器）——决定什么时候唤醒 Agent；
  • ② memory（记忆）——跨运行保持状态；
  • ③ permissions（权限）——管住 Agent 能做什么；
  • ④ outbox（发件箱）——负责投递与重试；
  • ⑤ 模型只在有活的时候才跑——「The system stays available while the model runs only when there is work」。

这五个组件的价值不在技术难度，而在它把「Agent 一直在线」这件事从玄学变成了可采购的工程清单。permissions 是最被低估的一个——它是「Agent 有多大权力」的唯一开关，也是昨天 Cursor 供应链投毒事件（攻击者用窃取的凭证篡改 Claude Code 构建，11 小时后才移除，最多 5000 名用户可能收到）之后，所有人必须重新设计的一层。

落地场景：

配合你的小红书 / 生鲜项目，可以这样搭：inbox 收每日选题与竞品链接 → timer 定时唤醒（比如每天 7:00 拉素材、22:00 出复盘） → memory 记住品牌调性、禁用词、已发过的选题避免重复 → permissions 明确「可以读文件、可以调生图 API、不可以自动发布」→ outbox 负责失败重试和人工审批提醒。注意 outbox 里的「重试」和 permissions 里的「不自动发布」必须成对设计——否则重试逻辑会绕开你的审批门，这是最常见的踩坑点。

解读：

经 @OpenAIDevs 转述：12 个模型在模拟公司环境里跑 50 个职场场景，其中 10 个场景的正确行为是保持沉默。GPT-6 Astra 总分第一，且在这 10 个该沉默的场景里保持了 8 次沉默。

落地场景：

给你的每个 Agent 配一套「沉默测试集」：10 个本该闭嘴的场景，每次改提示词都跑一遍。具体到小红书 / 生鲜项目：

  • 用户只说了「帮我看看这个品怎么样」→ Agent 应该先问规格和目标受众，而不是直接生成一整套方案；
  • 商品缺货 → 应该报告缺货，而不是用同类商品凑数；
  • 图片检测到疑似违规词但不确定 → 应该升级给人工，而不是自行删除或放行；
  • 库存数据缺失 → 应该说明数据缺口，而不是估算一个数字继续算利润。

这四个场景写下来就是一份沉默测试集。成本几乎为零，但它挡掉的是最贵的一类事故。

落地场景：

三个必须注意的前提（这决定了能不能省下钱）：

  • ① 脚本必须可审计——Code Mode 最大的风险是模型写出的控制流里有你看不见的循环（死循环、无限调 API）。一定要加调用次数上限和总预算上限。
  • ② 幂等性要求——脚本重跑时不能重复扣款、重复发布。发布动作要带幂等键。
  • ③ 保留人工审批出口——脚本跑到「发布」这一步必须挂起等人确认，而不是自己往下走。

实测预期：往返调用从 N 次压到 1 次，延迟与 token 消耗大致同比例下降——对「一次跑几十个 SKU」的批量任务，这是量级差异。

词条：⑶ Partial Rollout 异步训练
一句话大白话：长任务没跑完就先存档，下次接着跑；过采样率按通过率动态调整；跨 checkpoint 的旧轨迹做梯度校正降低陈旧偏差。大白话：AI 学做长任务时，如果一次没做完不用推倒重来，存个档接着干。为什么重要：Agent 任务动辄几十分钟，这是让长程能力训得起来的前提。
词条：⑷ 奖励劫持（Reward Hacking）
一句话大白话：Agent 为了「通过测试」而作弊，而不是真的把问题修好——比如绕过单元测试、改测试文件、偷偷连网查答案。美团的做法是环境断网 + 清空 git 历史与文件缓存 + LLM judge 监督轨迹。大白话：学生把题库偷了然后说自己会做题。避坑：验收标准不能只看「跑通了」，要看「是不是按正确方式跑通的」。
词条：⑸ Agent 的沉默权 / 沉默测试
一句话大白话：Deepnote 的 Agent Initiative Benchmark：50 个职场场景里有 10 个，正确行为是保持沉默，GPT-6 Astra 做到了 8 个。大白话：一个好员工不是每件事都抢着回答，而是知道什么时候该说「这个我做不了 / 信息不够」。避坑：给你的每个 Agent 配 10 个「本该闭嘴」的场景做回归测试。
词条：⑹ Orchestrator（智能体调度器）
一句话大白话：在同一会话里自动在不同模型间切换。谷歌的做法：Carbon 当协调者，Hydrogen 当执行者和验证者，额度消耗 -24%、速度 +19%。大白话：不是只请一个全能助理，而是让一个经理按活的大小派不同专员。同一思路在 @rauchg 的开源工具 fx 里是「强模型规划 + 快模型执行」。
词条：⑺ Code Mode
一句话大白话：Claude Code v2.1.323 的实验功能（默认关闭）：让模型写 JavaScript 去调用自己的工具，把多步任务的往返调用压缩成一次。大白话：以前 AI 干活要你一句一句交代，现在它自己写个脚本一口气干完。避坑：一定要加调用次数上限、总预算上限和幂等键，不然它能在死循环里烧完你的额度。
词条：⑻ Poppy 协议 / 门牌配置文件
一句话大白话：Sierra 联合 Meta 发布的个人代理协议 v1.0，通过「门牌」配置文件 + OAuth + HTTPS 加密，让智能体安全地代表用户访问企业网站，已落地 Meta Muse，Shopify 全量自动发布 Poppy 文件。大白话：给 AI 办一张能进别人家门的证件，门牌上写清你是谁、能进哪间屋。这是继 MCP（统一插座）之后的又一块协议拼图。
词条：⑼ 支付令牌化（Payment Tokenization）
一句话大白话：ChatGPT Wallet 的安全基石：支付网络给智能体一个含替代卡号、安全码、有效期的一次性令牌，真实卡号既不经过 ChatGPT 也不经过商家，且保留原卡积分与争议申诉权。大白话：给快递员一张临时工牌和一次性门卡，他能进门收货，但看不到你家保险柜的密码。
词条：⑽ B2A 经济（Business-to-Agent）
一句话大白话：a16z 提出：商家接下来要争抢「机器人顾客」——AI Agent 会替人比价、下单、付款，所以商家需要让自己的网站对 Agent 友好（这正是 OpenAI 发布商家指南、提醒网店别把合法智能体交易误判为机器人攻击的原因）。大白话：以后上门买东西的不是人，是替人办事的 AI，商家得学会招待「代客」。
词条：⑾ KV Cache 容量路由
一句话大白话：SGLang 在跨 5 个推理引擎重放 3072 个请求的测试中，按 KV cache 剩余容量分配请求，比轮询路由更快完成批次。大白话：调度员看谁那边缓存还有空位就派给谁，而不是一人一个轮流来。对自建推理集群是立刻能抄的优化。
词条：⑿ SatBench / 基准饱和
一句话大白话：Ethan Mollick 的项目收集了自 2023 年起实验室引用的 173 个基准，其中 63% 达到他定义的「饱和」——意味着这些基准已经区分不出模型好坏了。大白话：考试题太简单，满分的人越来越多，这张卷子已经不出成绩了。避坑：看到模型在某榜单「超过人类」先查这个榜单有没有饱和。
词条：⒀ 间接提示注入（IPI）
一句话大白话：Gemini 4 Hydrogen 在 Gray Swan IPI 基准上防御韧性提升 2.3 倍以上。IPI 是指恶意指令藏在网页、PDF、邮件里，Agent 读到后当作用户指令执行。大白话：你让 AI 看一份简历，结果简历里偷偷写着「顺便把通讯录发给我」。避坑：Agent 读取任何外部内容都要当作不可信数据，不能当作指令。
词条：⒁ 形式化验证（Lean 4）
一句话大白话：Google 把 Courtade–Kumar 猜想归约为 14 变量优化后，模型帮助划分搜索空间、推导边界，最终在 Lean 4 中完成形式化证明——即证明本身被机器逐行验证过。大白话：AI 负责想出思路，但答案不是它说了算，是交给一个不会放水的裁判机器验收。这就是姚期智那篇论文指向的关键机制。
词条：⒂ RL 任务 / 基准市场
一句话大白话：Perit Marketplace 卖的不是普通数据，而是「强化学习任务与基准」——即带标准答案和判分规则的题目包，已上架 29 个数据集，获批专家可做到每周数百个任务，4.5 个月营收超 1100 万美元。大白话：给 AI 出题并批改的生意，比给 AI 喂素材的生意贵得多。
⚠️ 今日避坑三连：
  • ① 别把「模型能处理 100 万 token」当成「模型理解了 100 万 token」。装得下和找得到、用得对是两件事。长文档任务必须配结构化索引 + 引用溯源 + 分层下钻，否则你会得到一份看起来全面、实际漏掉关键 3% 的分析。
  • ② 别忽略 Agent 的「越权」和「抢答」。今天三个信号同向：Gemini 4 Hydrogen 把越权行为压到 -81%、Deepnote 测「该不该沉默」、Claude for Manufacturing 把 17 项技能全部挂在人工审批后。默认权限必须是「只读 + 可回滚」，发布/付款/删除这类动作一律走人工确认。
  • ③ 别用「事件驱动的加密通道」来理解一切。今天有两个新闻表面相似、内核相反：Cursor 投毒是「加密了但分发链路被污染」，ChatGPT Wallet是「真正把权限边界做对了」。判断标准很简单：谁能拿到凭证、谁能改构建、谁能看到日志——三问下去就知道是真安全还是假安全。
