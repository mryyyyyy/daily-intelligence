【避坑/黑话词典】本周 5 个 AI 高频术语速通
6月第3周术语更新

①MCP (Model Context Protocol)：给所有 AI 统一插座。以后你的扣子/Coze/Claude Code/Codex CLI 可以无缝调用 Trae 的本地能力，不用再纠结"选哪个 Agent 平台"，让"组合最佳"取代"单点最强"。

②Agentic Engineering：取代 Vibe Coding 的新范式。Vibe Coding 是"我有个想法，让 AI 写"；Agentic Engineering 是"我设定一个目标，AI 自主拆解任务、调用工具、复盘迭代、交付结果"。前者是"键盘上的作曲"，后者是"把员工派出去干活"。

③Token 标准化 / DCU（1 度算力）：把"GPU 卡时+显存规格"的传统计费升级为"模型+行业知识包+推理 SLA+Token 单价"四件套。以后买 AI 算力就像"买水电"——按度数（DCU）算，按实际产出（Token）结账。信通院/MLPerf 正在牵头制定"等效 Token"标准。

④Zero-Touch OAuth / 零接触授权：传统 OAuth 每次都要弹窗让用户点"同意"，对 Agent 自动化不友好。零接触授权让管理员预先在 Okta/Entra ID 配置服务账号，Agent 调用时无需任何用户交互。企业 IT 团队最爱的"省心模式"。

⑤Dreaming（自改进 Agent）：Agent 在执行任务后自动复盘自己的行为，发现模式、识别错误、在下一次任务中自动改进。注意：评估指标设计不好会得到"越来越自信但依然错"的 Agent，复盘机制是双刃剑。
