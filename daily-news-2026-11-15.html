1【建设亚太共同体 促进共同繁荣】创新亚太 携手同行
📰 新闻联播说了什么

「创新」是 2026 年 APEC「中国年」确定的三大优先领域之一。习近平主席在出席亚太经合组织第三十一次领导人非正式会议时指出：「我们要牢牢抓住新一轮科技革命和产业变革机遇，在人工智能、量子信息、生命健康等前沿领域加强交流合作，营造开放、公平、公正、非歧视的创新生态，推动亚太地区实现生产力跃升。」

节目用四个具体案例把这句话落地：

  • 【印尼】基于中国开源模型研发的一款语言大模型上线，让这个有着 700 多种语言的"万岛之国"能更顺畅地与世界交流；
  • 【区域级数据】在中国开源大模型的带动下，亚太地区平均每天有超百个衍生模型出现；
  • 【增长预期】尽管贸易紧张持续、能源受到冲击，APEC 区域经济的全年增速预期仍旧稳定在 3.2%，继续扮演全球经济增长的"稳定器"与"主引擎"角色；
  • 【制度升级路径】从"数据"第一次被单列议题，到将「开源」首次提升至 APEC 部长级合作层面，再到共同擘画"亚太能源共同体"。数据显示，2024 年至 2025 年间 APEC 成员经济体发起的数字领域合作项目数量达到 225 项；APEC 经济体的互联网人口普及率已由 2014 年时的 52% 升至近 90%；去年全球新增的可再生能源装机，四分之三来自 APEC 经济体。

节目还给出两个"创新高地"的硬数据：在深圳「机器人谷」的开源平台，200 多家机器人供应链企业的接口标准、基础算法都可以开源共享，十几个 APEC 经济体的上千名开发者在这里围炉共创；来自墨西哥的创业者想给家乡牛羊开发一款 AI 检测设备（既能精准定位，又能通过 AI 算法实时监测健康状况），在平台上迅速找到硬件提供商，且模块开源可直接按想法更改配置。此外，中澳两国科研团队联合研发的大面积钙钛矿太阳能电池刷新了稳态效率的世界纪录（澳方参与材料开发、中方提供量产技术）。节目结语给出总账：平均每天诞生 8500 多件专利申请、平均每天有 1300 多台工业机器人走上生产线，均占全球八成以上；全球排名前十的创新集群，APEC 经济体占据了九席。

  • ① 工程端：10 月份，全国工程机械开工率同比提高 0.7 个百分点，连续两个月同比、环比增速转正，反映出工程项目施工节奏稳步加快。分区域看，西北地区风光大基地项目开工热度较高；西南、华南、华东地区交通基建、产业配套等项目建设提速。政策接续发力，「六张网」等重大工程项目加快推进，带动投资指标有所回暖，结构持续优化。
  • ② 投资端（本条最硬）：与算力、数据等相关的新型基础设施项目中标金额同比增长 45.4%；人工智能等前沿领域资本投资金额同比增长三倍多。
  • ③ 消费端：10 月份，各类线下消费支付金额同比增长 2.6%。
🧭 风向标解读

这是本期的信息含量最高但最容易被当成背景音的一条。国家信息中心是发改委直属的国家级数据发布机构，"先行指标"通常领先于 GDP 与社融 1—2 个月，因此这组数字实际上是对"10 月政策是否真的落地"给出的官方答案。

  • 「算力、数据相关新基建项目中标金额同比 +45.4%」——这是与 AI 产业最直接相关的官方口径。注意用词是"中标金额"而非"投资额"，说明订单已落到具体项目合同层面，不是意向。算力基建（智算中心、IDC、算力网络、液冷、电源）产业链的订单能见度至少覆盖到明年一季度。
  • 「人工智能等前沿领域资本投资金额同比增长三倍多」——三倍以上的增速，是在国家发改委系统口径下被表述的，可信度高。这印证了一个判断：AI 的一级市场没有冷下去，只是从"买人买卡"转向"买场景买数据买应用"。结合昨日的数据——11 月 13 日 A 股三大指数收跌（上证 -0.59%、深成指 -2.05%、创业板指 -3.32%），一二级市场正在明显背离：一级市场火热、二级市场回调。对应策略是不追高二级 AI 概念股，转向有真实中标订单的算力基建环节。
  • 「线下消费支付金额同比 +2.6%」看似平淡，实则是给消费板块的定心丸。在没有大规模消费刺激新政的背景下，2.6% 的正增长说明 10 月"六张网"等重大工程与以旧换新类政策已经在托底，而非空转。
  • 「工程机械开工率连续两个月同比、环比增速转正」是最经典的领先指标，连续两个月转正在历史上通常对应后续 3—6 个月的基建实物工作量改善。西北风光大基地开工热度高这一条，直接指向特高压、光伏、储能的订单节奏。

  • ① 跨本体技能迁移（Cross-embodiment transfer）：过去训练机械臂和双足人形机器人做同一任务必须从零教起；GR00T 2 构建了物理交互的共享表示，一次演示的技能可以迁移到另一种机器人本体上，只需极少重训。官方数据：50 个任务中，单次示范平均成功率 71%，5 次示范达 95%。
  • ② 内置世界模型（world-modelling）：模型在执行动作前先预测自己的动作会如何改变物理环境。官方表述很直白——"这就是把反应型机器人和会推理的机器人区分开来的那一层"。
  • ③ 战略层：延续 Project GR00T 在 GTC 2024 确立的开放生态路径（CUDA → cuDNN → 开放模型），英伟达要做的不是卖芯片，而是成为物理 AI 栈的平台层。

同日的对照事件（这组对比才是重点）：OpenAI 解散了独立机器人研发团队，理由是 GPT-6 Astra 等通用前沿模型已展现出直接操控机器人的潜力——在英伟达的一项测试中，由 Astra 驱动的智能体在模拟机器人操作基准中拿到 74.8% 的成功率，而此前专用机器人模型保持的最好成绩仅为 51.0%。CMU 机器人研究所助理教授 Guanya Shi 的解读是：机器人不再是需要专门攻克的技术难题，而更像通用智能落地的一个应用场景。

🎯 实战价值：

适合什么场景：小团队做机器人不再需要为每种本体单独采数据——你有一个人形机器人的演示数据，可以直接迁移到另一台机械臂上，这直接把具身智能的数据采集成本打下来一个数量级。

变现机会与判断：注意这天的两条消息方向相反但结论一致——英伟达开源世界模型让"机器人本体"变便宜，OpenAI 解散专用团队让"通用模型"变通用。对个人开发者最现实的机会不是自训模型，而是做"本体之间的技能搬运工"：收集演示数据、做跨本体迁移适配、做垂直场景（仓储分拣、养殖监测、门店理货）的落地集成。顺带一提，同期中国的星尘智能发布了 CoMind 多机协同框架，自变量机器人的 GreatWall 通用具身大模型通过广东省备案（历时 5 个月安全评估、20 万次抽检、27148 道高风险拒答测试）——国内在这一层的合规化进度实际走在前面。

🔥 核心黑科技：

1动态：Anthropic 公开「始终在线 Agent」的五个组件
🔧 解读：

Anthropic 官方给出的"长驻 Agent"五件套，被 @dotey 完整拆解转发：① 持久收件箱（durable inbox）+ 定时器决定 Agent 何时醒来；② 记忆（memory）跨运行保持状态；③ 权限（permissions） govern 允许的动作；④ 发件箱（outbox）处理投递与重试。官方原话要点是：系统保持可用，但模型只在有活干的时候才运行。

技术原理上，这解决了 Agent 化最大的两个工程痛点：一是"没有任务就烧 token"——用 inbox + timer 做触发，把 Agent 从"常驻轮询"改成"事件驱动"；二是"运行中断即失忆"——用持久化记忆跨运行保持状态；三是"Agent 乱来"——用权限层做硬边界，而不是靠提示词约束；四是"发出去了但没送到"——用 outbox + 重试保证交付。

🎯 落地场景：

这五件套直接对应到你的日常项目：

  • 小红书生鲜项目：把"每日竞品价格监控"做成 inbox 触发（爬到新数据就入 inbox），用 memory 记住每个竞品的历史价位曲线，用 permissions 限定 Agent 只能改价不能改库存，用 outbox 保证日报一定发出去——这才是能连续跑 90 天不坏的自动化，而不是一个跑一次就中断的脚本。
  • 配合本期 GitHub 榜上的 Tencent/LoopForge（自带 human approval gates）：LoopForge 管"审批门"，Anthropic 五件套管"运行时"，两者叠加就是一个可上生产的 Agent 交付流水线。

这个玩法的核心是"把 AI 放在一个极窄、极专业的知识缝隙里"：通用大模型无法独立完成哥德尔速记的解读，但"AI 负责跨文献检索与推理 + 形式化验证器负责证伪"的组合，让原本需要数年的人工工作压缩到几天。而且真值的裁判权交给了机器而非另一个 AI——这是它比"AI 总结古文献"高明的地方。

🎯 落地场景：

  • 落地要点：一定要配一个独立的"证伪器"。他用证明检查器抓出 50 个假命题，如果只用"另一个 AI 再读一遍"，大概率也会被骗。判据必须是可执行的规则、数据库或确定性计算，而不是另一个模型的主观判断。

一句话大白话：MCP 是"AI 和工具之间的插座"，AG-UI 是"AI 和人之间的插座"。今天 GitHub 榜上 ag-ui-protocol/ag-ui（17,358 star）就是它。用途：让 Agent 在你的前端网页里实时流式地把"我现在在想什么、正在做什么、要不要你确认"呈现出来，用户在对话框里点一个按钮就能给 Agent 插一个指令。做 ToB 产品的必看——没有它，Agent 就是个黑盒进度条。
词条：⑵ 协调者模式（Coordinator Pattern）
一句话大白话：不是让 10 个 Agent 互相喊话，而是派 1 个"经理 Agent"发号施令。Anthropic 的 MAMUBench 实测：协调者模式拿到 64% 的最优结果，团队模式只有 30%；而且团队从 4 人扩到 16 人时，真正干活的 Agent 比例从 66% 掉到 10%。一句话记住：Agent 越多，不是越能干，是越在互相等。
词条：⑶ 沉默测试（Agent Initiative Benchmark）
一句话大白话：考 Agent 不只是"会不会干活"，还要考"该不该干活"。Deepnote 的基准里 50 个职场场景有 10 个的正确答案是"闭嘴"，GPT-6 Astra 在这 10 个里保持了 8 次沉默。今天所有自动化事故——Cursor 投毒、Agent 越权、FAA 那次"AI 背锅"——本质都是"本不该出手却出手了"。给自己 Agent 加一条沉默规则，是今天投入产出比最高的动作。
词条：⑷ KV Cache 路由（KV-Cache-Aware Routing）
一句话大白话：把请求发给"缓存里刚好装得下"的显卡，而不是排队轮流发。@sgl_project 的实测：3072 个请求在 5 个推理引擎间重放，按 KV cache 容量路由比轮询更快完成整个批次。原理：模型的中间结果（KV cache）占显存，路由对了就不用反复重算。做本地推理集群，第一件该做对的事就是这个。
词条：⑸ 观测压缩（Observation Compression）
一句话大白话：Agent 的钱主要花在"它读过的东西"上，不是它说的话上。清华的 CoACT 在 SWE-bench Verified 上把总 Token 消耗砍掉 33.0%，而 PASS@1 基本不变，已入选 ICSE 2027。配套的激进版是 GitHub 榜上的 caveman——让 Agent 用穴居人说话，砍 65% token（省更多，但有损）。
词条：⑹ 跨本体迁移（Cross-embodiment Transfer）
一句话大白话：教过一次的动作，换一台机器人也能直接用，不用从头再教。英伟达 GR00T 2 的核心能力，官方数据：50 个任务里单次示范平均成功率 71%、5 次示范达 95%。这直接打掉的是"每种机器人都要单独采数据"的最大成本项——注意这是"表示层"突破，不是"更大模型"。
词条：⑺ 世界模型（World Model）
一句话大白话：让 AI 在动手之前，先在脑子里"演练一遍"结果会怎样。GR00T 2 内置世界模型，官方说法是"这就是把反应型机器人和会推理的机器人区分开来的那一层"。类比：人不会被玻璃门撞一次才知道该推还是该拉，AI 现在开始能预判了。这是机器人从"演示视频好看"到"真能上产线"的分水岭。
词条：⑻ 始终在线 Agent 五件套（Durable Agent Stack）
一句话大白话：让 Agent 像员工一样 24 小时待命，但只在有事时才烧钱。五个部件：持久收件箱 + 定时器（何时醒来）、记忆（跨运行记状态）、权限（能做什么）、发件箱 + 重试（投递保证）。Anthropic 官方原话：系统保持可用，模型只在有活干时才运行。这是"脚本"和"Agent"的分界线。
词条：⑼ 冻结训练禁令（Training Injunction）
一句话大白话：法院直接禁止你"研发下一代模型"，不是罚钱，是不许你做产品。11 月 12 日美国四家非营利组织依据加州《反不正当竞争法》起诉 OpenAI、谷歌、Anthropic、Meta、SpaceX AI 部门，请求禁止开发"能力超过现有最强系统"的模型、禁止运行以自主自我改进为目标的项目。注意：这是用消费者保护法管研发行为的罕见救济，一旦成立就是全行业的刹车。
词条：⑽ 结构性许可缺失（No-License Release）
一句话大白话：号称开源却没写 license，等于"谁都能看，但谁都能用吗？不一定"。无界方舟 Edge0-145B 号称首个完全本地运行的 145B 开源模型（48GB 笔记本峰值 29GB、80+ tokens/s），但官方发布帖始终没有标注许可证，技术报告也还没出。商用前务必确认授权状态——这是能省下律师费的一条。
词条：⑾ 专利悬崖（Patent Cliff / Incubation Period）
一句话大白话：申请文件要等 18 个月才公开，在此之前你是"公开但不能告"，公开之后才开始算 20 年专利期。药品专利有"数据独占期"延迟条款，但器械类没有。中国的医药器械出海必须按 18 个月倒推时间表——这是今天医药器械行业"赴美上市"讨论中绕不开的变量。
词条：⑿ 知识产权前置（IP Front-Running）
一句话大白话：你的方案被投资人/合作方拿着去申请专利，你才知道。今天的热词，指向"先谈合作、先发论文、先路演"这三种常见动作的副作用。实操建议：核心方案先提交专利，再对外交流；给投资人看的是"实施例"而不是"全部细节"。
词条：⑬ 具身智能的"零样本泛化"（Zero-shot Generalization）
一句话大白话：没人教过它，它自己做对了。这是具身智能最值钱也最难的能力——教一个新动作要人遥操作示范几百次，能零样本泛化就等于省掉这条成本曲线。今天的证据两面：智元 LIFE 框架让 FindingDory 从 37.5% 升到 65.8%、SSS-Bench 从 40.9% 升到 60.5%（官方自报），平均耗时从 554.7 秒降到 80.6 秒；但优必选签约 13361 台 vs 年内实际交付下调到 1500—2000 台，说明工程化交付仍是硬伤。
词条：⑭ 供应链投毒（Supply-chain Poisoning）
一句话大白话：不改你电脑上的代码，改你信任的那个"分发渠道"里的包。Cursor 案例：攻击者用偷到的存储访问密钥，10 月 29 日在扩展市场缓存里放了被篡改的 Claude Code 副本，约 11 小时后移除，最多约 5000 名用户可能拿到。对交付方的启示：发布前做哈希签名 + 可复现构建，CI 里加缓存层比对。
词条：⑮ 语义化版本契约（Semantic Versioning Contract）
一句话大白话：llama.cpp 从 v1.0.0 开始，主版本号一变就意味着公共 C API 破坏了，你不用每次都被动打补丁。官方理由很实在："很多下游应用依赖我们的工作，我们希望兼容性边界对这些开发者更清晰。"对做商业软件的人：今天起应该立刻升级依赖并锁版本——这是所有把 llama.cpp 编进产品的团队都应该做的一件事。
🧨 今日避坑三连
  • ① 别把"开源"当成一个二元标签，要问三件事：有没有 license、有没有技术报告、数据来源能不能商用。今天最典型的例子是无界方舟 Edge0-145B——参数与性能数据都很好看（145B、29GB、80+ tokens/s），但官方发布帖没写 license。一个没有 license 的"开源"模型进你的商业产品，等于给自己埋一个法务雷。
  • ② 别在多 Agent 团队里用"点对点沟通"这种看起来很聪明的架构。Anthropic 的 MAMUBench 已经用 77 个场景证明了：协调者模式 64% vs 团队模式 30%，团队从 4 人扩到 16 人时实际行动比例从 66% 崩到 10%，且 58% 的回合含对同伴的无依据陈述。派一个经理 Agent，其余 Agent 只交结构化产出、不互相说话——这是今天最该改的一条工作流设计。
  • ③ 别在关键流程里让 AI"总能说出点什么"。Deepnote 的基准里 50 个场景有 10 个的正确答案是沉默；Cursor 的投毒、FAA 的"AI 背锅"时刻，本质都是 AI 在不该出手时出手。给每个 Agent 配一条"沉默测试集"——10 个本该闭嘴的场景，每次改提示词都跑一遍。
