🧭 风向解读：这是继"人工智能+"行动之后，国家层面首次将AI与就业政策进行制度化绑定。规划以"十五五"五年规划为载体，意味着AI不再仅是技术议题，而是上升为宏观经济治理工具。规划暗含两个核心信号：一是国家承认AI对就业的替代效应不可逆，主动求"人机协同"而非简单"保住岗位"；二是把"AI赋能就业服务"作为创业方向，鼓励社会资本进入AI+招聘/培训/职业规划赛道。
💼 行业影响：直接受益：AI+HR SaaS、AI面试工具、AI职业培训、AI创业孵化；间接受益：智能客服替代人工、自动化办公、RPA企业服务；承压领域：传统呼叫中心、基础数据录入岗、初级翻译岗。投资方向关注"AI职业匹配平台"、"AI心理咨询"、"AI技能微证书"等创业机会。

词条 1：MCP（Model Context Protocol）

大白话：AI 界的"USB 接口标准"——给所有 AI 模型统一插座。以后你的 Claude Code 可以无缝调用 Cursor 的本地能力、调用 TimesFM 预测、调用 Agent-Reach 抓数据，不用再纠结选哪个 Agent。

词条 2：RAG（Retrieval-Augmented Generation）

大白话：让 AI 考试时"开卷"——每次回答前先从你的私有知识库（文档/数据库/网页）里查最新资料，再生成答案。解决"AI 一本正经胡说八道"和"知识过时"问题。TimesFM+codebase-memory-mcp 都属于 RAG 增强型工具。

词条 3：Agent 任务模式独立计费

大白话：OpenAI/Anthropic 学移动运营商——Agent 干活时单独按"任务"收费（不再共享 token 池）。后果是重度用户成本 5-10 倍上涨。规避方法：用本地模型（Ollama/Qwen3.7）+ MCP 协议 + 零 API 工具（Agent-Reach）。

词条 4：AI 主权（AI Sovereignty）

大白话：G7 埃维昂峰会的核心议题——每个国家要拥有自己的"AI 底座"（模型+算力+数据），不被美国出口管制卡脖子。中国筹办"世界人工智能合作组织"是对标动作。

词条 5：Diffusion LLM（扩散式大语言模型）

大白话：Google DeepMind 6月推出的 DiffusionGemma——抛弃传统"一个字一个字蹦"的生成方式，并行出整段文本，速度暴涨 4 倍且支持迭代式自纠错。预计 2026 下半年成主流 LLM 架构。
