👥 四种人结果（2×2）

A · 1999.12满仓.com股票

B · 1999.12清仓离场
躲过-78% + 等底部抄底
巴菲特、彼得·林奇、朱利安·罗伯逊、老虎基金在1999.12选择清仓或大幅减仓的人，躲过2000-2002的-78%暴跌，然后在2002.10纳指1,114点抄底。10万不变 → 抄底翻倍 → 20万+（算上2003-2007慢牛）
C · 持有少数"真赢家"
亚马逊200倍回报

D · 1999.12加杠杆抄底.com
下跌中途爆仓清零

💡 财商核心课（3条）

1
"顶部信号灯"是一组，不是一只。判断市场是否见顶不能用"巴菲特指标158%"单灯，要看6个信号灯齐亮——巴菲特指标>150% 顶部信号识别+ IPO首日平均>50% + 巴林信心指数>90% + 新开户暴增 + 储蓄率<3% + 身边朋友问买什么。3个灯亮=警惕；5个灯亮=该减仓；6个灯亮=主动退场。
2
"估值不是死的，是被打破的"。1999年互联网公司"没有PE"——这正是泡沫成熟的最强信号。当所有人开始说"传统估值对新经济失效"、"这次不一样"、"你只要不买就错过"，说明市场情绪已经进入"不可证伪伪"阶段。2000.3泡沫破裂后，巴菲特跑赢纳指超100个百分点（2000-2009年伯克希尔年化8.5% vs 纳指年化-5%）。
3
"分辨真生意 vs 假故事"是顶级投资的灵魂。2000年泡沫破裂后，超90%的.com公司破产，但Amazon、eBay、PayPal活下来成了万亿公司——15年后回报66倍。识别"用户真的有需求+有付费意愿+有护城河"的公司，是从"输家变赢家"的唯一机会。1999年如果你10万全买Amazon，2024年峰值670万——这就是"少数派赢家"的回报。

今天的暴跌≠顶部信号，而是底部信号的反向确认。今天的沪深300 PE 11.2倍（近十年26%分位）+科创50 PE 40.6倍（近十年7.9%分位）+融资余额两年低点+陆股通净流出230亿（多机构同时提醒"谨慎悲观情绪反应充分"）——这不是1999年12月，而是2008年12月 / 2018年12月 / 2020年3月的位置。

📊 巴林信心指数（Barron's Confidence Index）
美国道琼斯公司《巴林》杂志每周公布的债券收益率指标。计算公式：（10只AAA顶级债券平均收益率÷10只BBB中级债券平均收益率）×100。理论最大100%。指数值在80%左右通常被视为对股市的看跌信号——上升=信心增强（看涨），下降=信心减弱（看跌）。
🚀 IPO首日涨幅（IPO First-Day Pop）
新股上市首日的涨幅。1999-2000年平均+65%（VA Linux +697.5% / theGlobe.com +606% / WebMethods +507.5%）；对比1980年代平均7%、1990年代中期15%。当平均首日涨幅>50%时，市场已进入"非理性繁荣"。
👞 出租车司机荐股（Shoeshine Boy Indicator）
1929年约瑟夫·肯尼迪的鞋童定律延伸——当出租车司机、扫鞋童、餐馆服务员都开始向你推荐股票时，市场已经见顶（已在9/25详细化）。这是顶部信号里最"软"但最准的指标，因为"非专业人士都在入场"=最后的接盘者已经进场。
💰 储蓄搬家（Savers' Migration）
居民存款从银行账户大规模转入股市/基金的现象。美国1999年储蓄率从7%降至2%；A股2007年城乡居民储蓄首次负增长（16万亿→15万亿）。储蓄搬家=居民在用"保命钱"赌博=顶部信号。今天中国储蓄仍同比+10.6%=反向绿灯。
📈 巴菲特指标（Buffett Indicator）
股市总市值÷GDP。巴菲特2001年提出："最有效的单一估值指标"。70-80%=合理低估；100%=警戒；150%=极度泡沫。美股2024年峰值213%（历史第二高，仅次2021年190%）；2000年峰值153%。A股今天约68%（绿灯）。
板块 ③ 富爸爸一句话 · 别人贪婪时我恐惧
"恐惧与贪婪这两种偶尔爆发的
超级传染病，
将永远在投资界发生。
它们爆发的时间通常无法预测……
我们的目标比较简单：
我们只是'在别人贪婪的时候要恐惧，
在别人恐惧的时候要贪婪'。"
—— 沃伦·巴菲特《1986年致波克夏股东信》
（"恐惧与贪婪是超级传染病+逆向投资纪律"核心思想）

🔗 和今天案例的关联

这句话是今天6个顶部信号灯的总纲——巴菲特1986年就预见到"恐惧+贪婪"两种"超级传染病"会永远爆发，而他的应对方法不是预测时间，而是识别症状。今天我们学的6个顶部信号灯，就是"识别贪婪症状"的可操作清单。

2000年互联网泡沫的故事，把这句话体现得淋漓尽致：

① "恐惧与贪婪是超级传染病"=6个顶部信号灯齐亮——巴菲特指标153% / IPO首日+65% / 巴林信心指数>90% / 新开经纪账户暴增 / 美国储蓄率从7%降至2% / 出租车司机荐股。这6个灯就是"贪婪传染病"的6个临床症状，1999.12全部亮起。巴菲特不是"预言"了2000.3泡沫破裂，他只是看到了这6个症状。

② "它们爆发的时间通常无法预测"=巴菲特自己也错过了最佳逃跑时机——1999年伯克希尔跑输纳指50个百分点，被《巴伦周刊》封面嘲笑《沃伦，怎么回事？》。但巴菲特坚持"不预测，只识别"，最终5年后所有嘲笑者都在反思——纳指-78%而伯克希尔+40%。

③ "别人贪婪时我恐惧"=6个灯里5个亮=该减仓。今天2026.9.29的中国A股，6个灯是"0红3黄3绿"——典型"估值底部+情绪底部+杠杆累积"。巴菲特今天的态度：不是恐惧，也不是贪婪，而是"识别底部信号"。

对照2026.9.29的今天：美股3-4个顶部信号灯亮（巴菲特指标213%/席勒CAPE 40.94历史第二/美10Y国债5.24%创20年新高/AI算力股结构性泡沫）——巴菲特应该恐惧美股；中国A股 6个底部信号灯亮（沪深300 PE 11.2倍 / 融资余额两年低点 / 没人问买什么 / 储蓄不搬家）——巴菲特应该贪婪A股。这就是"别人贪婪时我恐惧，别人恐惧时我贪婪"的国别应用版。

一句话总结：6个顶部信号灯告诉你"什么时候恐惧"，
6个底部信号灯告诉你"什么时候贪婪"。
两句话合在一起=你能在1999.12恐惧+2008.12贪婪。
