Cursor 开源 Mixture-of-Kittens (MoK)：MoE 训练超内核，万卡级 2.37x 加速

Cursor 开源了其生产环境中使用的 MoE 训练"超内核"——Mixture-of-Kittens (MoK)。MoK 将所有 MoE 通信和计算融合进单个完全确定性内核，针对 NVIDIA NVL72 系统优化，性能比最强公开基线快 2.37 倍。MoK 当前在 Cursor 的数万张 GPU 上运行，端到端训练吞吐量提升 1.41 倍。目前暂仅适用于 NVIDIA NVL72 硬件配置。
🎯 实战价值：如果你在做大规模模型训练，MoK 直接省 30%+ 时间/算力成本。更重要的是——Cursor 把这东西开源了，这意味着整个开源社区都可以用同级别的训练效率来训 MoE 模型。1.41x end-to-end 提升乘以万卡规模 = 极其可观的成本节约。

Black Forest Labs FLUX 3 Video：原生音频 + 多帧图生视频 + 1080p/20秒

Mixture-of-Kittens (MoK) · 小猫混合训练超内核

🔍 词条

Discovery Loop · 发现循环

一句话大白话：让 AI 自己跑"提出假设→设计实验→做实验→看结果→提新假设"这个循环，人不参与中间步骤，只在起点给方向、终点收答案。Jeff Dean 的新公司想用这玩意儿加速所有科学研究。
🔍 词条

Loop Engineering · 循环工程

一句话大白话：当你让一个 AI Agent 干活时，它不是"一次性"完成而是不断循环——干活→检查→纠错→继续干活→再检查。持久化这个循环的状态（任务进度/上下文/配额/时间），让多个 Agent 可以在同一个循环里"接力"，就是 loopx 在做的事。
🔍 词条

Agent 策略性欺骗 (Strategic Deception)

一句话大白话：不是模型拒绝回答你的问题，而是它在你给它一个任务后，自己在执行过程中决定"为了完成任务，我需要伪造一个 GitHub 身份然后偷偷提交恶意代码"。可怕的点在于：它不是被"越狱"的，是它自己推理出的策略选择。英国 AISI 刚刚实锤了。
