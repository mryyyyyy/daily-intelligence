🔍 风向标解读

把《论减贫脱贫》放在当天第一条，说明脱贫成果的"制度化叙事"仍在延续但已不是主攻方向——出版专著是回望，不是加码。真正的增量信号在同一天并播的大湾区专题：关键词是"要素集聚"而不是"产业转移"。过去十年大湾区的逻辑是"把制造业产能搬进珠三角"，"十五五"的表述变成了"创新为引领 + 各类要素集聚"，这意味着政策重心从物理空间的产业转移转向制度空间的要素自由流动——跨境资本、跨境数据、跨境人才、跨境科研这四类要素的流动便利度，才是未来五年大湾区考核的核心变量。

需要警惕的是，这类"战略支点"表述在 A 股历史上往往对应主题炒作而非业绩兑现。从"锚定目标"到"五省协同细则落地"通常有 6–12 个月时滞。

📺 新闻联播说了什么

🔍 风向标解读

这组数字最反直觉的地方在于两个增速的巨大落差：外贸大盘同比 +20%，而进博会意向成交额只增长 2.3%。这两个数放在一起才构成完整信号——

  • 外贸 +20% 是"量"的胜利，不是"价"的胜利：在 44.81 万亿元的基数上还能保持 20% 增速，说明增量来自真实的出口数量扩张与新兴市场（东盟、中东、拉美、一带一路沿线）的份额提升，港口与航运的实物量数据可以交叉验证（宁波舟山港年集装箱吞吐量突破 4000 万箱）。
  • 进博会 +2.3% 是外资预期的真实读数：外资"稳住了"但没有回到扩张路径。这个数字不悲观也不乐观，属于典型的"存量维持 + 结构变化"——投资更集中在高技术、绿色、服务消费领域，而不再是重资产产能转移。
  • APEC 接棒是开放线的时间表：上海进博会闭幕后企业转场深圳参加 APEC 活动，说明官方有意把这一轮开放叙事做成"接力"而非单点事件，政策宣示密度会维持在高位。

3"十五五"民生举措：140 亿元中央预算内投资落地，教育 / 医疗 / 养老托育三线扩容
📺 新闻联播说了什么

11 月 11 日《新闻联播》报道，"十五五"时期我国将采取多项举措保障和改善民生。记者从国家发展改革委了解到，"十五五"时期国家将聚焦人民群众急难愁盼问题，实施更加公平普惠、精准有力的社会政策。具体部署包括：

  • 教育：支持普通高中教学楼、宿舍等设施建设，增加学位供给能力；支持有条件的地方建立新型研究型大学，建设一批办学特色鲜明的高水平职业本科学校。
  • 医疗：重点支持县域心电诊断、检查检验、影像等共享中心建设，提升重点中心乡镇卫生院服务水平；继续加力推进医院病房改造，让患者住院体验更舒适更顺心。
  • 养老托育：重点推进老旧养老机构改造升级和设备更新，提升失能失智老年人的照护能力；重点推进实现托育综合服务中心地市级全覆盖，发展托幼一体化服务，鼓励用人单位办托。

背景数据（11 月 10 日发改委"奋进'十五五'"系列新闻发布会，政策研究室副主任、新闻发言人李超主持，地区振兴司副司长冯垚、社会发展司副司长黄玮茹、价格司副司长张璐琴出席，40 余家媒体 50 余名记者参加）：2026 年已下达 140 亿元中央预算内投资。发布会还重点介绍革命老区建设、弱势群体保障、银发经济发展、重要民生商品保供稳价、公共服务价格政策等内容。

🔍 风向标解读

这是"十五五"民生投资的第一张时间表，也是当天唯一有明确资金量的政策。三个关键判断：

  • 140 亿只是"起步量"，不是总量。这是 2026 年已下达部分，"十五五"五年周期里教育、医疗、养老三条链的中央预算内投资盘子远大于此。真正的招标高峰在 2027 年。
  • 三个抓手都是"可下单的实物"：教学楼宿舍（基建）、县域共享中心（医疗设备打包采购）、老旧养老机构改造（适老设备）。政策语言从"提高认识"变成"支持建设"，意味着订单在路。
  • "鼓励用人单位办托"是这轮政策里最被低估的一句——它首次把企业福利体系与托育产业化绑定，直接打开 To B 的托育服务采购需求，而这恰恰是人口下行周期里唯一还有确定增量的细分。

另需注意"新型研究型大学"与"高水平职业本科"：这是本科层次教育供给结构改革的具体落点，高校建设与职教本科校的设备采购、实训设施需求会持续释放。

1动态：Google CEO 桑达尔·皮查伊 提出 "Decision as a First-Class API" —— 让模型做"闭集决策"而不是"生成文字"
🔍 解读（技术原理和实际意义）

皮查伊 11 月 11 日在 X 宣布发布 Gemini Decisions API，由新模型 Gemini Decision 1 驱动。他写道："Instead of generating text token by token, it's built for closed-set choices scoring up to 1,000 questions across text, images, audio, video + PDFs in a single pass."具体三点：

  • 3 种决策类型：是/否（yes/no）、多选（multiple choice，最多 255 个选项）、评分卡打分（rubric scoring）。
  • 价格：$0.10 / 百万输入 token，输出 token 计费 $0——官方称比 Flash-Lite 便宜约 5 倍。
  • 在多个基准上领先，校准误差（calibration error）最低；谷歌内部团队已在用它，Stitch Rapid 设计完整产品流程可达 1 倍速。

为什么这是"新概念"而不是"新 API"：过去所有 LLM API 的计费单位都是输出 token，而企业真正付费的其实是决策——"这张图有没有违规""这条评论该不该删""这个商品该不该上推荐位"。Decision API 把计费单位从"生成"改成"选择"，输出 token 归零意味着调用方不再为模型多说废话而付钱。这是从"文本生产工具"到"决策基础设施"的定位切换，也是对 OpenAI 推理模型定价体系的正面狙击。

🎯 落地场景

配合小红书生鲜项目：内容审核是天然的闭集决策场景——每张图/每段文案只需回答"合规/不合规"（yes/no）+ "打几分"（rubric scoring），不需要它写长文。用 Decision API 做自动化初审，人工只复核"不合规 + 低分"那部分，审核人力成本可降到原来的 1/5。同一套方法也适用于"这条差评该不该回复""这个商品描述有没有夸大宣传"。
